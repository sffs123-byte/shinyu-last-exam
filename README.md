# 국시 30년: 신유의 역습

직접 이동·공격·회피하며 김신유 보스를 공략하는 코믹 액션 게임입니다.
실존 인물의 실제 이력과 무관한 가상 패러디입니다.

## 플레이

https://sffs123-byte.github.io/shinyu-last-exam/

- PC: WASD/방향키 이동, J 딱밤, K 팩트탄, Space 회피, L 필살기.
- P/Escape 일시정지. 모바일에서는 조이스틱과 터치 버튼을 사용하세요.
- 첫 판에는 살살 모드를 추천합니다.
- 보스 처치 뒤 순둥 신유와 세 가지 실습을 완료하면 합격 엔딩이 나옵니다.

## 로컬 실행

순수 HTML/CSS/Canvas/JavaScript 정적 사이트입니다. 빌드·서버 API·DB·로그인이 필요 없습니다.

```sh
python3 -m http.server 8766
```

브라우저에서 http://localhost:8766 을 여세요.

GitHub Pages는 main 브랜치 루트에서 배포합니다.
